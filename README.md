# Shader Art — The tile, alive

A cross-stitch tile rendered as a living WebGL shader, drawn as dither dots: starbursts, stars, nested diamonds and square medallions, anchored by their centres while their arms reach, contract and pull.

Open `index.html` in a browser. Controls: pause/play, Scatter!, Crawl / Squirm / Breathe / Tempo sliders, a Dither dots toggle and a Dots density slider. Dark mode and reduced motion are respected.
